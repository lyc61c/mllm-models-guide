# MLLM 数据工程与评估：标准库练习

Python 3.10+，无需第三方库、GPU、模型权重或网络。

```bash
python lab.py --out lab-output
python -m unittest -v test_lab.py
```

在本目录执行以上命令；也可以从其他目录传入 lab.py 的完整路径。程序相对于脚本目录查找输入，输出到 `--out` 指定目录。

三个 JSON 文件都是人为构造的教学样例。`media_sha256` 来自模拟媒体标识字符串的 SHA256，并不指向可解码的真实图片。题目、标签和 A/B 预测均为预先编写，**没有运行模型，也不对应真实基准成绩**。`toy-predictions.jsonl` 是独立的评分练习，和数据划分练习的 train/dev/test 无对应关系。

练习内容：按 parent_id 或相同媒体哈希构建传递闭包；清除接触受保护媒体的整组样本；去除同媒体、同问题、同答案的精确重复；整组划分；断言无父文档/媒体交叉；计算教学版 ANLS、IoU、VQA 共识核心；按父文档进行配对 bootstrap，输出等父文档权重的平均差及经验百分位区间。

不实现：媒体下载/解码、感知哈希、语义近重复、官方答案归一化、真正的基准推理。不能把这套简化代码替代官方评测器。尤其 `norm()` 的 NFKC 和 casefold 只是练习约定。

`report.json` 记录输入指纹、删除日志、划分统计和逐例分数。练习区间只解释方法，不支持“A/B 哪个真实模型更好”的结论。
